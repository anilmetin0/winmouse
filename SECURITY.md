# Security policy

WinMouse is experimental, and its per-device HID behavior has not yet been validated with a
physical mouse.

## Reporting a vulnerability

Do not post vulnerability details or exploit steps in a public issue. Use GitHub's private
vulnerability reporting feature, currently enabled for this repository. If the feature is
unavailable, open a public issue asking for a private reporting channel without including technical
details.

The v0.1.0 prerelease is experimental and unsupported. Report issues against the current `main`
branch unless a report specifically affects that prerelease.
