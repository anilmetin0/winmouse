The Windows pointer and wheel, on your Mac

WinMouse is a free menu-bar app that gives an external mouse the Windows pointer curve, speed slider and wheel scrolling. Control + wheel zooms, and the side buttons go back and forward. Trackpads keep their macOS behaviour.

macOS 14 or later, Apple silicon and Intel. Open source, MIT license.

WinMouse for Mac

Download for Mac

The file is WinMouse-0.1.0.dmg. Its SHA-256 checksum is on the same release page.

  1. Install

    Open the downloaded file and drag WinMouse to the Applications folder.

  2. Open WinMouse the first time

    The app is not notarized, so macOS refuses to open it. Go to System Settings → Privacy & Security, scroll down and click Open Anyway. macOS asks once.

  3. Allow Accessibility

    When macOS asks, turn WinMouse on in System Settings → Privacy & Security → Accessibility. The wheel and the side buttons need it. The pointer curve works without it.

A mouse icon appears in the menu bar and the settings window opens. The icon pauses and resumes WinMouse.

Build from source

Needs Xcode or the Xcode Command Line Tools

git clone https://github.com/anilmetin0/winmouse.git
cd winmouse
./build.sh
cp -R build/WinMouse.app /Applications/
open /Applications/WinMouse.app

A local build gets a new signature every time, so macOS may forget the Accessibility permission after a rebuild. Remove WinMouse from the Accessibility list and add it again, or sign with your own certificate: CODESIGN_IDENTITY="Your Certificate" ./build.sh

The Windows pointer curve

With Enhance pointer precision on, Windows moves the pointer further for each count of a fast movement than of a slow one. WinMouse builds that curve from the Windows default curve and the pointer speed setting, and gives it to each external mouse as its acceleration table. With precision off, it uses the Windows linear speeds.

Move the slider or switch precision off. The curve follows.

  • No permission needed

    The curve is set on the mouse's own HID service. Accessibility access is only for the wheel and the buttons.

  • Put back when it stops

    WinMouse keeps each mouse's previous values and writes them back on pause, on quit, on a user switch and after a crash.

  • External mice only

    Built-in trackpads and the Magic Trackpad keep the macOS pointer.

Wheel scrolling like Chrome and Edge

On Windows, Chrome and Edge scroll 100 pixels per wheel notch and animate each notch for 200 ms. WinMouse scrolls the same distance with the same curve. It adds no speed-based acceleration and no momentum.

The wheel keeps the Windows direction when the trackpad uses natural scrolling. You can switch it to match the trackpad. Smooth scrolling turns off when Reduce Motion is on.

Control + wheel zooms

Each notch away from you presses ⌘ =, each notch toward you ⌘ −, so zoom works in Safari and also in Chrome, which ignores Control + wheel on the Mac. If macOS Zoom already uses Control with the wheel to zoom the screen, WinMouse leaves it alone.

Side buttons go back and forward

On Windows the side buttons go back and forward in every window, when you release them. WinMouse also acts on release, in three ways depending on the app.

Buttons passed through

These apps already handle the side buttons on a Mac and get them untouched.

  • Chrome
  • Edge
  • Firefox
  • VS Code
  • JetBrains IDEs

Back and Forward shortcuts

These apps ignore the buttons, so WinMouse presses ⌘[ and ⌘]. Xcode gets Control-Command-arrow.

  • Finder
  • Safari
  • System Settings
  • App Store
  • Music
  • TV
  • Preview
  • Xcode

Left alone

Other apps keep the raw buttons, because ⌘[ means indent in many of them. Games keep their own buttons.

The middle button, right-click and double-click already behave like Windows in macOS browsers, and WinMouse does not change them.

Scope and limits

What it leaves alone

  • Trackpads. The built-in trackpad, the Magic Trackpad and the Magic Mouse's touch scrolling keep their macOS behaviour.
  • Games and gestures. Apps that declare themselves games, and wheel gestures with Command or Option, are not changed.
  • System preferences. WinMouse writes no global preferences. It changes HID properties on each external mouse and keeps their original values. Unplugging the mouse or restarting the Mac also clears them.
  • Your data. There is no telemetry.

Where it differs from Windows

  • macOS measures a movement by its straight-line length. Windows adds the longer axis and half of the shorter one, so a diagonal movement counts as up to 12 % slower on the Mac and gets a little less acceleration.
  • When the mouse speeds up into a steeper part of the curve, Windows blends the old and new segments for one report. A macOS table cannot do that.
  • Side buttons reach only the apps listed above.
  • The shortcuts are sent as key positions. On keyboard layouts where [ or = sit on another key, an app that matches shortcuts by character may not react.

Questions

macOS says WinMouse can't be opened

WinMouse has no Developer ID signature and is not notarized by Apple, so macOS blocks the first launch. Open the app once and let macOS refuse it. Then go to System Settings → Privacy & Security, scroll to the message about WinMouse and click Open Anyway.

After that, WinMouse opens like any other app.

Why does it need Accessibility access?

To change wheel scrolling and the side buttons, WinMouse has to read and post input events, and macOS allows that only with Accessibility access. The pointer curve needs no permission.

The wheel stopped working after an update

macOS ties the Accessibility permission to the app's signature, and a new build can have a different one. Remove WinMouse from the list in System Settings → Privacy & Security → Accessibility and add it again.

The pointer feels wrong

WinMouse uses private HID interfaces, and a macOS update could change them. Quit WinMouse and reconnect the mouse, or restart the Mac. Either one clears the curve WinMouse set.

Another mouse utility that changes the same settings can also undo WinMouse's changes. The settings window names such an app when it finds one.

How do I check the download?

Download the .sha256 file from the same release into the same folder, then run this in Terminal there:

shasum -a 256 -c WinMouse-0.1.0.dmg.sha256

How do I remove WinMouse?

Quit WinMouse from its menu, delete it from Applications and remove it from the Accessibility list in System Settings. The mouse gets its previous settings back when WinMouse quits.
